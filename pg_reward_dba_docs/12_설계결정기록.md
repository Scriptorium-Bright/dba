## 2. 용어 정리 중 반드시 유지할 것

- PostgreSQL에서는 **Primary/Standby**, WAL, Crash Recovery, `CREATE PROCEDURE/CALL`.
- `Function = READ`, `Procedure = WRITE`는 PostgreSQL의 정확한 정의가 아님. PostgreSQL Function도 INSERT/UPDATE 가능.
- `RETURNING id`는 생성된 ID를 돌려주며, PL/pgSQL에서는 `RETURNING id INTO v_grant_id`로 받아 `wallet_ledger.reward_grant_id`에 사용.
- `RETURNING` 성공은 최종 COMMIT 성공을 뜻하지 않음.
- 체크포인트는 DBMS WAL REDO 복구 기준에 관계되며 미지급 대상 판정에는 사용하지 않음.
- `CREATE INDEX CONCURRENTLY`는 일반 DML을 허용하면서 인덱스 생성; 직접 트랜잭션 블록 불가.
